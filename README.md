# Frigorífico 3D – Plano interactivo de cámaras y túneles

Plano 3D interactivo del Frigorífico La Apacheta (Tierra Amarilla) para ver y gestionar pallets por folio.

**Ver la app:** https://paillaleferik-del.github.io/frigorifico-3d/

## Funciones
- Cámaras 1–6 y túneles 1–6 y 8–10 con calles numeradas.
- Pallets en piso y estiba, con etiqueta de folio.
- Buscador de folios: muestra cámara, calle y nivel, y marca el pallet.
- Ingreso, retiro y capacidad editable por cámara.
- Selección múltiple y despacho animado a camiones.

## Datos
En GitHub Pages la app funciona en modo **"Solo este dispositivo"**: los datos se guardan en el navegador de cada persona y no se comparten.

## Tecnología
HTML + JavaScript en un solo archivo, con three.js r128 desde cdnjs.
